# Security policy

## Supported version

TaskFlow is a portfolio project. Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting:

https://github.com/jorge-pires/projeto-kanban/security/advisories/new

Include:

- the affected route or feature;
- steps to reproduce;
- the potential impact;
- a suggested fix, when available.

Do not include real passwords, session tokens, database URLs or personal data. Reports will be acknowledged as soon as possible and fixed according to severity.
